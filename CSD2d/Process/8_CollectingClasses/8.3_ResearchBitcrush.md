## How to Bitcrush
- FORMULA: y[n] = QL * (int(x[n] / QL))  *Equation 19.1 Pirkle*  
  + *x[n]* = input
  + *y[n]* = output
  + *QL* = p / (pow(2, N) - 1)  *QL is "The discrete Quantization Level"*  
    + *N* = int [1, 16]         *N is the new Bit depth*
    + *p* = 1 when unipolar, 2 when bipolar (so pretty much always 2)
