## Low-Pass Filter (First order)
**FIRST: Calculating γ**
- FORMULA: γ = (cos(θ)) / (1 + sin(θ))
  + θ = 2π * (breakFreq / Samplerate)

**SECOND: Implementing IIR-Filter**  
- FORMULA: y[n] = ax[n] + ax[n-1] + by[n-1]
  + *x[n]* = input
  + *x[n-1]* = Previous input
  + *y[n-1]* = Previous output
  + *a* = (1 - γ) / 2
  + *b* = -γ
  - Also don't need a buffer for this, bc it's only one sample delay and i could just define *x[n-1]* first and then *x[n]* (same with y), like in the APF.
