## Low-Pass Filter (First order)
**FIRST: Calculating γ**  
- FORMULA: γ = (cos(θ)) / (1 + sin(θ))
  + θ = 2π * (breakFreq / Samplerate)

**SECOND: Implementing IIR-Filter**  
- FORMULA: y[n] = ax[n] + ax[n-1] - by[n-1]
  + *x[n]* = input
  + *x[n-1]* = Previous input
  + *y[n-1]* = Previous output
  + *a* = (1 - γ) / 2
  + *b* = -γ
  - Also don't need a buffer for this, bc it's only one sample delay and i could just define *x[n-1]* first and then *x[n]* (same with y), like in the APF.
Should be that easy! Didn't take long to figure this one out

## Linkwitz-Riley LPF
**FIRST: Calculating Greek letters**  
- FORMULA 1: theta_ = M_PI * breakFreq_ / sampleRate_;
- FORMULA 2: omega_ = M_PI * breakFreq_;
- FORMULA 3: kappa_ = omega_ / tan(theta_);
- FORMULA 4: delta_ = kappa_ * kappa_ + omega_ * omega_ + 2 * kappa_ * omega_;

**SECOND: Calculating Coeffs**  
- FORMULA 1: a0 = (omega_ * omega_) / delta_;
- FORMULA 2: a1 = 2 * a0;
- FORMULA 3: b1 = (-2 * kappa_ * kappa_ + 2 * omega_ * omega_) / delta_;
- FORMULA 4: b2 = (-2 * kappa_ * omega_ + kappa_ * kappa_ + omega_ * omega_) / delta_;

**THIRD: Implementing IIR-Filter**  
- FORMULA: y[n] = a0 * x[n] + a1 * x[n-1] + a0 * x[n-2] - b1y[n-1] - b2y[n-2]
  + *x[n]* = input
  + *x[n-1]* = Previous input
  + *x[n-2]* = Prevevious input
  + *y[n-1]* = Previous output
  + *y[n-2]* = Prevevious output

## Mapping [0, 1] to [50Hz, 18000Hz]
For the mapping of a knob to make sense i have to tweak the mapping a little:
- FORMULA: freq = fmin * pow((fmax/fmin), parameter)
  + freq = breakFreq put in setBreakFreq
  + fmin = minimal range boundary
  + fmax = maximal range boundary
  + parameter = knob number [0, 1]
This is nice to implement into the class itself, so I can just give it a [0, 1] value and it calculates the breakFreq.
