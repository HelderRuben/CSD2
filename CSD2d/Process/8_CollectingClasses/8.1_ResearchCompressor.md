# Different compressor components

## 1: Envelope Detector with built in Att/Rel
**FIRST: Setting attack/decay value:**  
  - **FORMULA: a_ = exp(2.2 / attRelTime * sampleRate)**  
    + *a_* = coefficient for attack or decay
    + *attRelTime* = user set value for attack or release
    + *sampleRate* = sampleRate (duh)
    - Implementing this is the way to set the attack and release time in ms instead of setting a 0-1 value
**SECOND: Taking average amplitude over samples**  
  - Don't need buffer bc just taking the average from start and adding to it  
  - **FORMULA: y_ = a_ * y_ + (1 - a_) * abs_x**  
    + *y_* = output (0 at start)
    + *a_* = attack or decay (betweeen 0 - 1 at start)
    + *abs_x* = the absolute value of the inputSample
    + *(1 - a_)* = Scaling
    - *a_* is initialized when making the envFollower, *x* is the sample when processing

## 2: Convert to dB
- FORMULA: inputdB = 20 * log10f(inputLin + tinyConst);
  + *inputdB* = amplitude converted to dB value
  + *inputLin* = amplitude in linear value  
  + *tinyConst* = 0.000001 (for ruling out *log10f(0)*)  

## 3: Gain Computer
- FORMULA: outputG = inputG                     *for inputG <= threshG*  
- FORMULA: outputG = thresh + (inputG - thresh) / ratio  *for inputG > thresh*  
  + *inputG* = RMS value converted to dB
  + *thresh* = threshold set by user in dB value (first convert to dB??)
  + *ratio* = ratio set by user (variable *1:ratio* in compressor)
  - I've already decided, I'm not doing a knee variable, i like hard knees and I want the compressor to be a noticable audio effect

## 4: (Auto?) Make-Up Gain
- FORMULA: outputG = inputG + makeupG
  + outputG = gain in dB
  + inputG = gain in dB
  + makeupG = make-up gain for compensating gain reduction
  - FORMULA: makeupG = -thresh * (1 - (1/ratio))
    + *thresh* = threshold set by user in dB value (first convert to dB??)
    + *ratio* = ratio set by user (variable *1:ratio* in compressor)

## 5: Convert back to Linear
- FORMULA: powf(10.0f, inputG / 20.0f);
  - Just converting back to Linear
