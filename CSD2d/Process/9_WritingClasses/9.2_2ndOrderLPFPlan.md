# LPF 2nd Order

Doing some research for the 2nd order just because its so fun!  
Making a step-by-step plan for implementing it

**FIRST: Setting variables and stuff:**   
theta_ = M_PI * breakFreq_ / sampleRate_;
d_ = 1 / Q_;
beta_ = 0.5 * (1 - (d_ / 2) * sin(theta_)) / (1 + (d_ / 2) * sin(theta_));
gamma_ = (0.5 + beta_) * cos(theta_);

a0_ = (0.5 + beta_ - gamma_) / 2;
a1_ = 0.5 + beta_ - gamma_;
b1_ = -2 * gamma_;
b2_ = 2 * beta_;  

**SECOND: Implementing IIR-Filter**  
- FORMULA: y[n] = a0 * x[n] + a1 * x[n-1] + a0 * x[n-2] - b1y[n-1] - b2y[n-2]
  + *x[n]* = input
  + *x[n-1]* = Previous input
  + *x[n-2]* = Prevevious input
  + *y[n-1]* = Previous output
  + *y[n-2]* = Prevevious output
