# References Used in SelfStudy

Keeping a Diary is great, but it gets confusion once you start using it as a reference (because of all the files and text). So hereby a list of things i (can) use, plus a quick description.

## Pirkle

"**Designing Audio Effect Plugins in C++ _ For AAX, AU, and -- William C Pirkle -- 2, 2019-05-08 -- Routledge, Taylor et Francis Group**"  
Fantastic book with clear descriptions of different audio effect plugins and how to make them. I have this book as a PDF.

## Julius O. Smith III

"**Physical Audio Signal Processing: for Virtual Musical Instruments and Digital Audio Effects
by Julius O. Smith III**"  
Found a nice book on audio effects, even with clear code for C++. Goes more in detail to incommensurate timings than others do.
